# Surface map credits

The bundled 2048 × 1024 planet, Sun and Moon maps are from
[Solar System Scope / INOVE](https://www.solarsystemscope.com/textures/),
distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The maps combine NASA imagery and elevation data with artistic adjustments;
they are reference textures, not live imagery.

Downloaded unchanged from the official collection. SHA-256 comparisons confirmed
that they match the corresponding textures in the project's earlier `gh-pages` build.
Only sphere geometry and UV coordinates are corrected in code; the images are unmodified.
